## 🔄 训练循环流程

```
开始训练
    │
    ▼
┌──────────────────────────────────────────────────────┐
│  初始化                                               │
│  • 创建 Actor, Critic, Temperature                   │
│  • 创建 Replay Buffer                                │
│  • 设置超参数                                         │
└──────────────────┬───────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│  采样阶段                                             │
│                                                       │
│  for step in range(max_steps):                       │
│      ┌─────────────────────────────┐                 │
│      │ 1. 采样动作                  │                 │
│      │    a = π(s) or random       │                 │
│      └──────────┬──────────────────┘                 │
│                 ▼                                     │
│      ┌─────────────────────────────┐                 │
│      │ 2. 执行动作                  │                 │
│      │    s', r, done = env.step(a)│                 │
│      └──────────┬──────────────────┘                 │
│                 ▼                                     │
│      ┌─────────────────────────────┐                 │
│      │ 3. 存储经验                  │                 │
│      │    buffer.insert(s,a,r,s')  │                 │
│      └──────────┬──────────────────┘                 │
│                 ▼                                     │
│      ┌─────────────────────────────┐                 │
│      │ 4. 训练网络 (if step > starts)│                │
│      │    见下方 "更新流程"          │                 │
│      └─────────────────────────────┘                 │
└──────────────────────────────────────────────────────┘
```

## 🎓 单步更新流程

### 标准更新 (update)

```
输入: batch = {s, a, r, s', mask}

┌──────────────────────────────────────────────────────┐
│  步骤 1: 更新 Critic (价值网络)                        │
│                                                       │
│  ┌─────────────────────────┐                         │
│  │ 1.1 采样下一个动作       │                         │
│  │     a' ~ π(·|s')        │                         │
│  │     log_prob = log π(a'|s')                      │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 1.2 计算 Target Q 值     │                         │
│  │     Q' = Q_target(s', a')│                        │
│  │     target = r + γ*Q'   │                         │
│  │     (可选) - α*log_prob  │                         │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 1.3 计算当前 Q 值        │                         │
│  │     Q = Q(s, a)         │                         │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 1.4 计算 Critic 损失     │                         │
│  │     L = (Q - target)²   │                         │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 1.5 梯度下降             │                         │
│  │     Q ← Q - η*∇L        │                         │
│  └─────────────────────────┘                         │
└──────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│  步骤 2: 更新 Actor (策略网络)                         │
│                                                       │
│  ┌─────────────────────────┐                         │
│  │ 2.1 采样动作             │                         │
│  │     a ~ π(·|s)          │                         │
│  │     log_prob = log π(a|s)                        │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 2.2 计算 Q 值            │                         │
│  │     Q = Q(s, a)         │                         │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 2.3 计算 Actor 损失      │                         │
│  │     J = Q - α*log_prob  │                         │
│  │     L = -J              │                         │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 2.4 梯度上升             │                         │
│  │     π ← π + η*∇J        │                         │
│  └─────────────────────────┘                         │
└──────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│  步骤 3: 更新 Temperature (温度参数)                   │
│                                                       │
│  ┌─────────────────────────┐                         │
│  │ 3.1 计算当前熵           │                         │
│  │     H = -E[log π(a|s)]  │                         │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 3.2 计算 Temperature 损失│                         │
│  │     L = α*(H - H_target)│                         │
│  └──────────┬──────────────┘                         │
│             ▼                                         │
│  ┌─────────────────────────┐                         │
│  │ 3.3 更新温度             │                         │
│  │     α ← α - η*∇L        │                         │
│  └─────────────────────────┘                         │
└──────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│  步骤 4: 更新 Target 网络                              │
│                                                       │
│  Q_target ← τ*Q + (1-τ)*Q_target                     │
│  (τ = 0.005, 软更新)                                  │
└──────────────────────────────────────────────────────┘
                   │
                   ▼
               返回 agent
```

## ⚡ 高 UTD 更新流程 (update_high_utd)

```
输入: batch (batch_size=256), utd_ratio=4

┌──────────────────────────────────────────────────────┐
│  步骤 1: 分割 batch 为 minibatches                     │
│                                                       │
│  ┌────────────────────────────────────┐              │
│  │  batch (256 samples)               │              │
│  └────────────────────────────────────┘              │
│               │ split into 4                          │
│               ▼                                       │
│  ┌────────┬────────┬────────┬────────┐              │
│  │mini 1  │mini 2  │mini 3  │mini 4  │              │
│  │ (64)   │ (64)   │ (64)   │ (64)   │              │
│  └────────┴────────┴────────┴────────┘              │
└──────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│  步骤 2: 循环更新 Critic (utd_ratio 次)                │
│                                                       │
│  for i in range(utd_ratio):  # 4 次                  │
│      ┌─────────────────────────┐                     │
│      │ mini_i → 更新 Critic    │                     │
│      │   只更新 Q 网络          │                     │
│      │   不更新 Actor           │                     │
│      └──────────┬──────────────┘                     │
│                 ▼                                     │
│      ┌─────────────────────────┐                     │
│      │ agent_i ← 更新后的 agent│                     │
│      └─────────────────────────┘                     │
│                                                       │
│  使用 jax.lax.scan 高效循环                           │
└──────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│  步骤 3: 一次更新 Actor 和 Temperature                 │
│                                                       │
│  ┌─────────────────────────┐                         │
│  │ 完整 batch (256 samples)│                         │
│  │     ↓                   │                         │
│  │ 更新 Actor              │                         │
│  │ 更新 Temperature        │                         │
│  └─────────────────────────┘                         │
└──────────────────────────────────────────────────────┘
                   │
                   ▼
            返回 final_agent


对比分析:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

标准更新 (utd_ratio=1):
  256 samples → 1 次 Critic 更新
               1 次 Actor 更新

高 UTD 更新 (utd_ratio=4):
  256 samples → 4 次 Critic 更新  ← 充分利用数据！
               1 次 Actor 更新

样本效率提升: 4x
```

## 🎨 Critic 损失计算详解

```
输入: batch = {s, a, r, s', mask}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 1: 采样下一个动作
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

s' (batch_size, obs_dim)
    │
    ▼
┌─────────────┐
│   Actor     │  π(·|s')
└──────┬──────┘
       │
       ▼
a' ~ N(μ, σ)  (batch_size, action_dim)
log_prob = log π(a'|s')  (batch_size,)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 2: 计算 Target Q 值 (使用 Target 网络)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

      s', a'
         │
         ▼
┌──────────────────┐
│  Target Critic   │  Q_target(s', a')
│  (ensemble_size) │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Ensemble:       │
│  Q_1'(s', a')    │
│  Q_2'(s', a')    │
│  ...             │
│  Q_N'(s', a')    │
└────────┬─────────┘
         │
         ▼ take min
min_Q' (batch_size,)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 3: 计算 Bellman Target
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

target = r + γ * mask * min_Q'

可选: 添加熵项
target = r + γ * mask * (min_Q' - α * log_prob)
                         └──────┬─────┘
                           熵奖励


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 4: 计算当前 Q 值
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

      s, a
        │
        ▼
┌─────────────┐
│   Critic    │  Q(s, a)
│ (ensemble)  │
└──────┬──────┘
       │
       ▼
┌──────────────┐
│  Q_1(s, a)   │
│  Q_2(s, a)   │
│  ...         │
└──────┬───────┘
       │
       ▼
Q_values (ensemble_size, batch_size)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 5: 计算 TD Error 和损失
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TD_error = Q(s, a) - target
           └───┬──┘   └──┬──┘
           预测值     目标值

Loss = E[(TD_error)²]
     = E[(Q(s,a) - target)²]

对每个 Critic 计算损失，然后平均
```

## 🎯 Actor 损失计算详解

```
输入: batch = {s, ...}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 1: 采样动作 (重参数化技巧)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

s (batch_size, obs_dim)
    │
    ▼
┌─────────────┐
│   Actor     │  π(·|s)
└──────┬──────┘
       │
       ▼
┌──────────────────┐
│ μ(s), σ(s)       │
└────────┬─────────┘
         │
         ▼ 重参数化
┌──────────────────┐
│ ε ~ N(0, 1)      │
│ a = μ + σ * ε    │
└────────┬─────────┘
         │
         ▼
a (batch_size, action_dim)
log_prob = log π(a|s)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 2: 评估动作
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

      s, a
        │
        ▼
┌─────────────┐
│   Critic    │  Q(s, a)
│ (ensemble)  │
└──────┬──────┘
       │
       ▼ mean
Q_avg (batch_size,)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 3: 计算目标和损失
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Objective = Q_avg - α * log_prob
            └──┬──┘   └────┬────┘
            价值最大化  熵最大化
            (exploitation) (exploration)

Loss = -E[Objective]
     = E[α*log_prob - Q_avg]

梯度上升 Objective ≡ 梯度下降 Loss
```

## 🌡️ Temperature 自动调整

```
目标: 保持策略熵 ≈ target_entropy

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
当前状态
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

计算当前熵:
H(π) = -E[log π(a|s)]

比较:
H(π) vs H_target

          │
          ▼
┌──────────────────────┐
│   H < H_target?      │  策略太确定
│                      │
│   → 增大 α           │  ← 鼓励探索
│   → 更随机           │
└──────────────────────┘
          │
          ▼
┌──────────────────────┐
│   H > H_target?      │  策略太随机
│                      │
│   → 减小 α           │  ← 鼓励利用
│   → 更确定           │
└──────────────────────┘


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
更新规则 (Lagrange 乘子)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Loss = α * (H - H_target)

梯度:
∂Loss/∂α = H - H_target

更新:
α ← α - learning_rate * ∂Loss/∂α
  = α - learning_rate * (H - H_target)

如果 H < H_target:
  → (H - H_target) < 0
  → α 增大
  → 更多探索

如果 H > H_target:
  → (H - H_target) > 0
  → α 减小
  → 更多利用
```

## 🎭 双 Q 网络机制

```
问题: 单 Q 网络容易过估计

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
单 Q 网络 (容易过估计)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

      s'
       │
       ▼
┌─────────────┐
│  max_a Q(s',a) │  ← 总是选最大的
└─────────────┘     (包括噪声导致的高估)
       │
       ▼
    过估计


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
双 Q 网络 (减少过估计)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

      s', a'
       │  │
       ▼  ▼
┌──────────────┐  ┌──────────────┐
│  Q_1(s', a') │  │  Q_2(s', a') │
└──────┬───────┘  └──────┬───────┘
       │                 │
       └────────┬────────┘
                ▼
          min(Q_1, Q_2)  ← 取最小值
                │            (保守估计)
                ▼
            更准确


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SAC 使用 Ensemble (2-10 个 Critic)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

标准 SAC (ensemble_size=2):
  Q_target = min(Q_1, Q_2)

REDQ (ensemble_size=10, subsample_size=2):
  随机选 2 个 → Q_target = min(Q_i, Q_j)
  
  优势:
  • 更好的泛化
  • 更高的样本效率
```

## 🔄 Target 网络软更新

```
问题: 直接用当前网络计算 target 不稳定

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
硬更新 (DQN 风格)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

每 N 步 (例如 10000):
  Q_target ← Q  (完全复制)

时间线:
t=0:     Q_target = Q_0
t=1-9999: Q 不断变化，Q_target 不变
t=10000: Q_target = Q_10000  (突然跳变)
         ↑
      不够平滑


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
软更新 (SAC 风格)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

每步:
  Q_target ← τ * Q + (1-τ) * Q_target
             ↑           ↑
           新参数      旧参数
           (τ=0.005)

时间线:
t=0: Q_target = Q_0
t=1: Q_target = 0.005*Q_1 + 0.995*Q_0
t=2: Q_target = 0.005*Q_2 + 0.995*Q_target(t=1)
...  (平滑变化)

优势:
• 训练更稳定
• target 变化平滑
• 减少震荡
```

## 🎯 总结

SAC 算法的核心流程:

```
1️⃣ Actor-Critic 协同
   Actor  → 学习策略
   Critic → 评估价值

2️⃣ 最大熵目标
   max E[reward + α * entropy]
   → 自动探索

3️⃣ 双 Q 网络
   min(Q_1, Q_2)
   → 减少过估计

4️⃣ 软目标更新
   Q_target ← τ*Q + (1-τ)*Q_target
   → 训练稳定

5️⃣ 高 UTD
   每步数据 → 多次更新
   → 样本高效

6️⃣ 温度自动调整
   α ← α + η*(H - H_target)
   → 探索-利用平衡
```

这就是 SERL 中 SAC 算法的完整工作流程！🚀
