**观测空间**:

**成功标准**:
- Episode Return > 0 (初始约 -50)

- 移动到目标位置附近

## 🎓 理解训练过程

### 时间线

```
0-30秒:
  Learner: 等待数据
  Actor: 随机探索，收集 1000 条经验
  
30秒:
  Learner: Buffer 填充完成，开始训练
  Actor: 继续随机探索
  
30秒后:
  Learner: 持续训练，每 30 步发送新参数
  Actor: 收到参数后，开始使用策略
  
1-5分钟:
  策略逐渐改进
  Episode Return 从 -50 提升到 -20
  
5-15分钟:
  机械臂学会靠近方块
  Episode Return 提升到 0 左右
  
15-30分钟:
  学会稳定抓取和移动
  Episode Return > 10
```

### 数据流动

```
┌─────────────┐                    ┌─────────────┐
│   Actor     │                    │   Learner   │
│             │                    │             │
│ 1. 采样动作 │                    │ 3. 采样 batch│
│ 2. 执行动作 │──── 经验 ────────►│ 4. 更新网络 │
│ 5. 收到参数 │◄─── 参数 ─────────│ 6. 发送参数 │
│             │                    │             │
└─────────────┘                    └─────────────┘
```

## 🔍 关键代码解读

### Actor 做什么？

```python
# 1. 采样动作
if step < 300:
    action = env.action_space.sample()  # 随机
else:
    action = agent.sample_actions(obs)  # 策略

# 2. 执行
next_obs, reward, done, truncated, info = env.step(action)

# 3. 存储
data_store.insert({
    'observations': obs,
    'actions': action,
    'rewards': reward,
    ...
})

# 4. 接收新参数 (自动)
```

### Learner 做什么？

```python
# 1. 等待 Buffer 填充
while len(buffer) < 1000:
    wait()

# 2. 训练循环
for step in range(max_steps):
    # 采样数据
    batch = buffer.sample(256)
    
    # 更新网络
    agent = agent.update(batch)
    
    # 发送参数 (每 30 步)
    if step % 30 == 0:
        server.publish(agent.params)
```

## 🛠️ 调试技巧

### 问题 1: Actor 一直等待

**现象**: 
```
Waiting for server...
```

**解决**: 确保先启动 Learner

### 问题 2: 渲染窗口不显示

**原因**: `--render` 标志

**检查**:
```bash
# run_actor.sh 中应该有 --render
cat run_actor.sh | grep render
```

### 问题 3: 训练很慢

**原因**: CPU 训练比 GPU 慢

**正常速度**:
- CPU: ~20-30 steps/sec
- GPU: ~100-200 steps/sec

**加快训练**:
```bash
# 方法 1: 去掉渲染
# 编辑 run_actor.sh，删除 --render

# 方法 2: 减少训练步数
--max_steps=100000  # 从 1M 改为 100K
```

### 问题 4: 想看训练曲线

```bash
# 1. 删除 run_learner.sh 中的 --debug
vim run_learner.sh
# 删除最后的 --debug

# 2. 重新启动
# 3. 访问 https://wandb.ai 查看
```
