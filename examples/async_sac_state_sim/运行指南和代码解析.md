## 🧠 核心概念解释

### 1. 异步 Actor-Learner 架构

```
┌─────────────────────────────────────────────────────────┐
│                                                           │
│  ┌──────────────┐                  ┌──────────────┐     │
│  │   Actor      │                  │   Learner    │     │
│  │  (环境交互)   │                  │  (策略训练)   │     │
│  │              │                  │              │     │
│  │ • 采样动作   │◄─── 参数更新 ────│• 从 Buffer   │     │
│  │ • 执行动作   │                  │  采样数据    │     │
│  │ • 收集经验   │──── 经验数据 ────►│• 计算梯度    │     │
│  │              │                  │• 更新网络    │     │
│  └──────────────┘                  └──────────────┘     │
│         ↓                                  ↑              │
│         │                                  │              │
│         └───────► QueuedDataStore ◄────────┘              │
│                  (经验数据队列)                            │
│                                                           │
└─────────────────────────────────────────────────────────┘
```

**为什么要异步？**
- ✅ Actor 可以持续收集数据，不用等待训练完成
- ✅ Learner 可以高效使用 GPU 训练，不用等待环境执行
- ✅ 提高整体训练效率

### 2. 训练时间线


### 3. SAC 算法简介

**SAC (Soft Actor-Critic)** 是一个强化学习算法，包含三个关键组件：

```python
# 1. Actor (策略网络) - 决定采取什么动作
π(a|s) → 给定状态 s，输出动作 a

# 2. Critic (Q 网络) - 评估动作的好坏
Q(s, a) → 给定状态 s 和动作 a，输出预期回报

# 3. Temperature (温度参数) - 控制探索程度
α → 探索 vs 利用的权衡
```

**训练流程：**
1. Actor 在环境中采样动作
2. 收集经验 (s, a, r, s')
3. Learner 从 Buffer 采样数据
4. 更新 Critic (学习价值函数)
5. 更新 Actor (改进策略)
6. 更新 Temperature (调整探索)

```python
def actor(agent: SACAgent, data_store, env, sampling_rng):
    """
    Actor 的工作:
    1. 与环境交互
    2. 收集经验数据
    3. 发送到 Learner
    4. 接收更新的参数
    """
    
    # ===== 第一步: 连接到 Learner =====
    client = TrainerClient(
        "actor_env",              # 标识符
        FLAGS.ip,                 # Learner 的 IP (默认 localhost)
        make_trainer_config(),    # 配置
        data_store,               # 数据存储
        wait_for_server=True,     # 等待 Learner 启动
    )
    # 👆 这里会阻塞，直到 Learner 的 Server 启动
    
    # ===== 第二步: 设置参数更新回调 =====
    def update_params(params):
        nonlocal agent
        # 用新参数替换旧参数
        agent = agent.replace(state=agent.state.replace(params=params))
    
    # 注册回调：当收到新参数时自动调用 update_params
    client.recv_network_callback(update_params)
    
    # ===== 第三步: 创建评估环境 =====
    eval_env = gym.make(FLAGS.env)
    if FLAGS.env == "PandaPickCube-v0":
        eval_env = gym.wrappers.FlattenObservation(eval_env)
    eval_env = RecordEpisodeStatistics(eval_env)
    # 👆 这个 wrapper 会自动记录 episode 的回报和长度
    
    # ===== 第四步: 主循环 =====
    obs, _ = env.reset()
    for step in tqdm.tqdm(range(FLAGS.max_steps), dynamic_ncols=True):
        
        # --- 4.1: 采样动作 ---
        if step < FLAGS.random_steps:
            # 前 300 步：随机探索
            actions = env.action_space.sample()
            print(f"Step {step}: Random action")
        else:
            # 之后：使用策略采样
            sampling_rng, key = jax.random.split(sampling_rng)
            actions = agent.sample_actions(
                observations=jax.device_put(obs),  # 放到 GPU
                seed=key,                          # 随机种子
                deterministic=False,               # 随机策略 (探索)
            )
            actions = np.asarray(jax.device_get(actions))  # 拿回 CPU
        
        # --- 4.2: 执行动作 ---
        next_obs, reward, done, truncated, info = env.step(actions)
        # next_obs: 下一个状态
        # reward: 即时奖励
        # done: 是否完成任务
        # truncated: 是否超时
        
        next_obs = np.asarray(next_obs, dtype=np.float32)
        reward = np.asarray(reward, dtype=np.float32)
        running_return += reward
        
        # --- 4.3: 存储经验 ---
        data_store.insert(
            dict(
                observations=obs,           # 当前状态
                actions=actions,            # 执行的动作
                next_observations=next_obs, # 下一个状态
                rewards=reward,             # 奖励
                masks=1.0 - done,          # 1=继续, 0=终止
                dones=done or truncated,   # 是否结束
            )
        )
        # 👆 这些数据会自动发送到 Learner 的 Replay Buffer
        
        # --- 4.4: 重置环境 (如果需要) ---
        obs = next_obs
        if done or truncated:
            print(f"Episode ended. Return: {running_return}")
            running_return = 0.0
            obs, _ = env.reset()
        
        # --- 4.5: 定期更新参数 ---
        if step % FLAGS.steps_per_update == 0:  # 每 30 步
            client.update()  # 检查是否有新参数
        
        # --- 4.6: 定期评估 ---
        if step % FLAGS.eval_period == 0:  # 每 2000 步
            evaluate_info = evaluate(
                policy_fn=partial(agent.sample_actions, argmax=True),
                env=eval_env,
                num_episodes=FLAGS.eval_n_trajs,  # 评估 5 个 episode
            )
            stats = {"eval": evaluate_info}
            client.request("send-stats", stats)  # 发送到 Learner 记录
```

### Part 3: Learner 函数 (第 178-257 行)

```python
def learner(rng, agent: SACAgent, replay_buffer, replay_iterator):
    """
    Learner 的工作:
    1. 接收 Actor 发来的数据
    2. 训练策略网络
    3. 发送更新的参数给 Actor
    """
    
    # ===== 第一步: 设置日志 =====
    wandb_logger = make_wandb_logger(
        project="serl_dev",
        description=FLAGS.exp_name or FLAGS.env,
        debug=FLAGS.debug,  # True 时不上传到云端
    )
    
    update_steps = 0  # 训练步数计数器
    
    # ===== 第二步: 设置统计回调 =====
    def stats_callback(type: str, payload: dict) -> dict:
        """当收到 Actor 的统计信息时调用"""
        assert type == "send-stats"
        if wandb_logger is not None:
            wandb_logger.log(payload, step=update_steps)
        return {}
    
    # ===== 第三步: 创建 TrainerServer =====
    server = TrainerServer(
        make_trainer_config(),
        request_callback=stats_callback
    )
    server.register_data_store("actor_env", replay_buffer)
    # 👆 将 replay_buffer 注册到 server
    #    Actor 发送的数据会自动插入到 replay_buffer
    
    server.start(threaded=True)  # 在后台线程启动
    print("Server started, waiting for actor...")
    
    # ===== 第四步: 等待填充 Replay Buffer =====
    pbar = tqdm.tqdm(
        total=FLAGS.training_starts,  # 目标: 1000 条
        initial=len(replay_buffer),   # 当前: 0 条
        desc="Filling up replay buffer",
    )
    
    while len(replay_buffer) < FLAGS.training_starts:
        pbar.update(len(replay_buffer) - pbar.n)
        time.sleep(1)  # 每秒检查一次
    
    pbar.close()
    print(f"Buffer filled! Size: {len(replay_buffer)}")
    
    # ===== 第五步: 发送初始网络 =====
    server.publish_network(agent.state.params)
    print_green("sent initial network to actor")
    # 👆 Actor 会收到这些参数，开始使用策略采样
    
    # ===== 第六步: 训练循环 =====
    timer = Timer()  # 计时器
    
    for step in tqdm.tqdm(range(FLAGS.max_steps), desc="learner"):
        
        # --- 6.1: 从 Buffer 采样数据 ---
        with timer.context("sample_replay_buffer"):
            batch = next(replay_iterator)
            # batch = {
            #     'observations': (batch_size, obs_dim),
            #     'actions': (batch_size, act_dim),
            #     'next_observations': (batch_size, obs_dim),
            #     'rewards': (batch_size,),
            #     'masks': (batch_size,),
            # }
        
        # --- 6.2: 更新 Agent ---
        with timer.context("train"):
            utd_ratio_int = int(FLAGS.utd_ratio)  # 1
            
            # 这是核心！更新 SAC 算法
            agent, update_info = agent.update_high_utd(
                batch,
                utd_ratio=utd_ratio_int
            )
            # update_info = {
            #     'critic_loss': ...,
            #     'actor_loss': ...,
            #     'q1': ...,
            #     'q2': ...,
            #     'entropy': ...,
            # }
            
            agent = jax.block_until_ready(agent)
            # 👆 等待 GPU 计算完成
            
            # --- 6.3: 发送更新的参数 ---
            server.publish_network(agent.state.params)
            # 👆 Actor 的 recv_network_callback 会收到这些参数
        
        # --- 6.4: 记录日志 ---
        if update_steps % FLAGS.log_period == 0 and wandb_logger:
            wandb_logger.log(update_info, step=update_steps)
            wandb_logger.log(
                {"timer": timer.get_average_times()},
                step=update_steps
            )
            # 可以在 wandb 网站上看到训练曲线
        
        # --- 6.5: 保存检查点 ---
        if FLAGS.checkpoint_period and update_steps % FLAGS.checkpoint_period == 0:
            checkpoints.save_checkpoint(
                FLAGS.checkpoint_path,
                agent.state,
                step=update_steps,
                keep=20  # 保留最近 20 个
            )
        
        update_steps += 1
```

### Part 4: Main 函数 (第 262-330 行)

```python
def main(_):
    # ===== 第一步: 设置设备 =====
    devices = jax.local_devices()  # 获取所有设备 (CPU/GPU)
    num_devices = len(devices)
    sharding = jax.sharding.PositionalSharding(devices)
    # 👆 用于分布式训练 (多 GPU)
    
    assert FLAGS.batch_size % num_devices == 0
    # 确保 batch_size 能被设备数整除
    
    # ===== 第二步: 设置随机种子 =====
    rng = jax.random.PRNGKey(FLAGS.seed)  # 42
    # 👆 确保实验可复现
    
    # ===== 第三步: 创建环境 =====
    if FLAGS.render:
        env = gym.make(FLAGS.env, render_mode="human")
        # 👆 会打开可视化窗口
    else:
        env = gym.make(FLAGS.env)
    
    # PandaPickCube-v0 返回 dict 观测，需要展平
    if FLAGS.env == "PandaPickCube-v0":
        env = gym.wrappers.FlattenObservation(env)
    
    # ===== 第四步: 创建 SAC Agent =====
    rng, sampling_rng = jax.random.split(rng)
    agent: SACAgent = make_sac_agent(
        seed=FLAGS.seed,
        sample_obs=env.observation_space.sample(),
        # 👆 传入一个样本观测，用于推断网络输入维度
        sample_action=env.action_space.sample(),
        # 👆 传入一个样本动作，用于推断网络输出维度
    )
    
    # 将 agent 复制到所有设备 (多 GPU 训练)
    agent: SACAgent = jax.device_put(
        jax.tree_map(jnp.array, agent),
        sharding.replicate()
    )
    
    # ===== 第五步: 启动 Learner 或 Actor =====
    if FLAGS.learner:
        # --- Learner 模式 ---
        sampling_rng = jax.device_put(sampling_rng, device=sharding.replicate())
        
        # 创建 Replay Buffer
        replay_buffer = make_replay_buffer(
            env,
            capacity=FLAGS.replay_buffer_capacity,  # 100 万
            rlds_logger_path=FLAGS.log_rlds_path,
            type="replay_buffer",
            preload_rlds_path=FLAGS.preload_rlds_path,
        )
        
        # 创建迭代器
        replay_iterator = replay_buffer.get_iterator(
            sample_args={
                "batch_size": FLAGS.batch_size * FLAGS.critic_actor_ratio,
                # 256 * 8 = 2048 (因为 Critic 更新更频繁)
            },
            device=sharding.replicate(),
        )
        
        print_green("starting learner loop")
        learner(
            sampling_rng,
            agent,
            replay_buffer,
            replay_iterator=replay_iterator,
        )
    
    elif FLAGS.actor:
        # --- Actor 模式 ---
        sampling_rng = jax.device_put(sampling_rng, sharding.replicate())
        
        # 创建数据存储 (Actor 端的队列)
        data_store = QueuedDataStore(2000)
        # 👆 最多存储 2000 条经验 (超出会阻塞)
        
        print_green("starting actor loop")
        actor(agent, data_store, env, sampling_rng)
    
    else:
        raise NotImplementedError("Must be either a learner or an actor")
```

## 🔍 关键代码片段解析

### 1. 如何采样动作？

```python
# 在 Actor 中
if step < FLAGS.random_steps:
    # 方法 1: 随机采样 (探索阶段)
    actions = env.action_space.sample()
    # 例如: array([0.1, -0.5, 0.3, 0.8])
else:
    # 方法 2: 使用策略采样
    sampling_rng, key = jax.random.split(sampling_rng)
    actions = agent.sample_actions(
        observations=jax.device_put(obs),
        seed=key,
        deterministic=False,  # False = 随机策略, True = 确定性
    )
```

**deterministic 的区别：**
- `False`: 从分布 π(a|s) 采样，带探索噪声
- `True`: 取均值 μ(s)，用于评估

### 2. SAC 更新做了什么？

```python
# 在 Learner 中
agent, update_info = agent.update_high_utd(batch, utd_ratio=1)

# 内部实际执行:
# 1. 更新 Critic (Q 网络) - 8 次
for _ in range(critic_actor_ratio):  # 8
    # 计算 TD 误差
    target_q = reward + γ * min(Q'(s', a')) - α*log π(a'|s')
    critic_loss = MSE(Q(s, a), target_q)
    
    # 梯度下降
    critic_params = optimizer.update(critic_params, grads)

# 2. 更新 Actor (策略网络) - 1 次
for _ in range(1):
    # 计算策略梯度
    actor_loss = E[α*log π(a|s) - Q(s, a)]
    
    # 梯度下降
    actor_params = optimizer.update(actor_params, grads)

# 3. 更新 Temperature (温度参数)
temp_loss = -α * (log π + target_entropy)
temp = optimizer.update(temp, grads)
```

## 📚 进阶阅读

### 1. SAC 算法原理

**论文**: [Soft Actor-Critic](https://arxiv.org/abs/1801.01290)

**核心思想**: 最大化期望回报 + 策略熵

```
J(π) = E[ Σ γ^t (r_t + α H(π(·|s_t))) ]
       ↑          ↑       ↑
       回报       折扣    熵奖励
```

### 2. 异步训练的优势

**传统同步训练**:
```
for step in range(max_steps):
    action = policy(obs)
    obs = env.step(action)  # ← 等待环境
    train(data)              # ← 等待训练
```

**异步训练**:
```
Actor 进程:                Learner 进程:
while True:                while True:
    action = policy(obs)       batch = buffer.sample()
    obs = env.step(action)     train(batch)
    send(data)                 update_policy()
    
# 两者并行运行，互不阻塞
```

## 🎓 总结

**核心流程**:
1. Learner 启动 → 等待数据
2. Actor 启动 → 连接 Learner → 随机探索
3. Buffer 填充到 1000 条
4. Learner 开始训练 → 发送新参数
5. Actor 收到参数 → 使用策略采样
6. 循环 4-5，策略逐渐改进

**关键概念**:
- **异步架构**: Actor 和 Learner 并行运行
- **Replay Buffer**: 存储历史经验，随机采样
- **SAC 算法**: 最大化回报 + 熵，鼓励探索
