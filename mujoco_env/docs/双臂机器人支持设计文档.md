## 📋 背景

当前的 `mujoco_env` 架构主要针对**单臂机器人**设计，支持单agent的RL训练。然而，在真实的工业场景中，双臂协作是非常重要的能力，例如：

- **装配任务**: 一个手臂固定零件，另一个手臂安装
- **物体操作**: 协作抓取大型或复杂形状的物体
- **高精度任务**: 一个手臂作为参考系，另一个手臂进行精细操作



---

## 🎯 设计目标

1. **保持向后兼容**: 单臂机器人的API不变

2. **灵活性**: 支持对称和非对称双臂配置

3. **可扩展性**: 未来可扩展到多臂（>2）系统

4. **清晰性**: API简洁易懂

   

---

## 🏗️ 架构设计

### 方案A: 多Agent架构（推荐）

将双臂视为**两个独立的agent**，每个agent有自己的观测空间和动作空间。

#### 优势
- ✅ 符合多agent RL的标准范式
- ✅ 可以使用现有的多agent RL算法（MAPPO, MADDPG等）
- ✅ 每个手臂可以独立控制
- ✅ 容易扩展到>2个手臂

#### 劣势
- ⚠️ 需要修改 `RobotManipulationEnv` 支持多agent
- ⚠️ 观测空间和动作空间需要重新设计

#### 接口示例

```python
from mujoco_env.mujoco_env.envs import MultiArmManipulationEnv

env = MultiArmManipulationEnv(
    robots=["diana_med", "diana_med"],  # 两个手臂
    tasks=["dual_grasp"],  # 双臂任务
    controller_types=["cartesian_impedance", "cartesian_impedance"],
    num_agents=2,
)

# 观测空间：字典，每个agent一个key
obs, info = env.reset()
# obs = {
#     "arm0": {
#         "observation": np.array(...),
#         "achieved_goal": np.array(...),
#         "desired_goal": np.array(...),
#     },
#     "arm1": {
#         "observation": np.array(...),
#         "achieved_goal": np.array(...),
#         "desired_goal": np.array(...),
#     }
# }

# 动作空间：字典，每个agent一个key
actions = {
    "arm0": np.array([...]),
    "arm1": np.array([...]),
}
obs, reward, terminated, truncated, info = env.step(actions)
# reward = {
#     "arm0": 0.5,
#     "arm1": 0.5,
#     "__all__": 1.0  # 全局奖励
# }
```

### 方案B: 单Agent+连接动作（简单）

将双臂视为一个**扩展的单agent**，动作空间是两个手臂的连接。

#### 优势
- ✅ 最小化代码改动
- ✅ 可以直接使用现有的单agent RL算法
- ✅ 实现简单快速

#### 劣势
- ❌ 动作空间维度加倍，难以训练
- ❌ 不符合多agent RL范式
- ❌ 难以扩展到>2个手臂
- ❌ 无法独立控制每个手臂

#### 接口示例

```python
from mujoco_env.mujoco_env.envs import RobotManipulationEnv

env = RobotManipulationEnv(
    robot_name="dual_diana_med",  # 双臂机器人
    task_name="dual_grasp",
    controller_type="cartesian_impedance",
)

# 观测空间：扩展的单agent
obs, info = env.reset()
# obs = {
#     "observation": np.array([...]),  # 包含两个手臂的状态
#     "achieved_goal": np.array([...]),
#     "desired_goal": np.array([...]),
# }

# 动作空间：连接的动作
action = np.array([...])  # 维度 = 2 * DOF
obs, reward, terminated, truncated, info = env.step(action)
```

### 方案C: 层次化架构（高级）

使用**层次化RL**，高层策略决定协作策略，低层策略控制各个手臂。

#### 优势
- ✅ 符合人类的协作思维模式
- ✅ 可以学习高层协作策略
- ✅ 低层策略可以预训练或迁移

#### 劣势
- ❌ 实现复杂度高
- ❌ 需要专门的层次化RL算法
- ❌ 训练难度大

### 3. MultiArmManipulationEnv

```python
class MultiArmManipulationEnv(BaseRobotEnv):
    """多臂机器人操作环境"""
    
    def __init__(
        self,
        robots: List[str],
        tasks: str,
        controller_types: List[str],
        num_agents: int = 2,
        control_freq: int = 20,
        render_mode: Optional[str] = None,
        **kwargs
    ):
        """
        Args:
            robots: 机器人名称列表
            tasks: 任务名称
            controller_types: 每个机器人的控制器类型列表
            num_agents: Agent数量
            control_freq: 控制频率
            render_mode: 渲染模式
        """
        super().__init__(render_mode=render_mode)
        
        self.num_agents = num_agents
        self.agents = [f"arm{i}" for i in range(num_agents)]
        
        # 为每个agent创建观测空间和动作空间
        self.observation_space = spaces.Dict({
            agent: self._create_obs_space()
            for agent in self.agents
        })
        
        self.action_space = spaces.Dict({
            agent: self._create_action_space()
            for agent in self.agents
        })
    
    def step(
        self, 
        actions: Dict[str, np.ndarray]
    ) -> Tuple[Dict, Dict, Dict, Dict, Dict]:
        """
        Args:
            actions: {"arm0": action0, "arm1": action1}
            
        Returns:
            observations: {"arm0": obs0, "arm1": obs1}
            rewards: {"arm0": r0, "arm1": r1, "__all__": r_global}
            terminateds: {"arm0": False, "arm1": False, "__all__": False}
            truncateds: {"arm0": False, "arm1": False, "__all__": False}
            infos: {"arm0": info0, "arm1": info1}
        """
        pass
```

```python
def test_dual_arm_training():
    """测试双臂训练流程"""
    env = MultiArmManipulationEnv(
        robots=["diana_med", "diana_med"],
        tasks="dual_grasp",
        controller_types=["cartesian_impedance", "cartesian_impedance"],
        num_agents=2,
    )
    
    # 训练100步
    obs, info = env.reset()
    for _ in range(100):
        actions = {
            agent: env.action_space[agent].sample()
            for agent in env.agents
        }
        obs, rewards, terminateds, truncateds, infos = env.step(actions)
        
        if terminateds["__all__"] or truncateds["__all__"]:
            obs, info = env.reset()
    
    env.close()
```

## 📋 结论

双臂机器人支持是 `mujoco_env` 的重要扩展方向。推荐采用**方案A（多Agent架构）**，因为它：

1. 符合标准的多agent RL范式
2. 可以利用现有的多agent RL算法
3. 易于扩展到多臂系统
4. API设计清晰
